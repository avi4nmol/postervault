# PosterVault — Movie Poster Website

This is a static, beginner-friendly website. It is ready to publish with GitHub Pages, Netlify, Vercel, or another static host.

## Important
The poster visuals in this starter site are original CSS compositions and fictional titles. Replace them only with artwork/images you have permission to use.

## Custom domain
1. Publish the site on GitHub Pages / Netlify / Vercel.
2. Buy your domain from a registrar.
3. Add the domain in your hosting provider's "Custom Domain" settings.
4. Follow the registrar DNS records supplied by the host.
5. Replace the Pinterest website URL with your final domain.

## Suggested brand
PosterVault

You can rename the brand directly in `index.html`.
